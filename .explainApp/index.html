Life Dashboard Guide

3分で人生の軌道に戻るホーム画面

Start Console、Reminder、カテゴリ別の今日、Life Balance、Knowledge、Logs、Notion連携の役割を、図とユースケースで確認できます。

全体像 3分再起動 Learning Lab 画面 データ 運用

Purpose

管理するためではなく、始めるためのアプリ

このアプリの中心は、完璧な記録ではありません。今日の一手を選び、Resourceを開き、5分だけ始め、必要ならReminderで戻り、終わったらLearning Logに残すことです。

Daily Flow

毎日の使い方

疲れている日でも、操作は「見る、開く、始める、記録する」だけに寄せます。

1

見る

Todayで「今やること」を確認します。

2

開く

関連ResourceやShortcutから教材、Notion、開発環境へ移動します。

3

始める

5分だけ始めるか、15分集中します。

4

残す

Timer終了後、Learning Logへ自動補完して保存します。脱線しやすい日はReminderをONにします。

Learning Lab

Cloud Questと自由Sandbox

Questは順番固定ではありません。ネットワーク、セキュリティ、IAM、DB、障害対応から、気になる演習を好きなタイミングで選びます。

Quest Mode

CLI、Cloud Console、Code Runnerで達成条件を満たし、Learning Logに保存します。

Sandbox Mode

Quest外で自由に疑似クラウドを触り、試行錯誤そのものを学習ログにできます。

ログ連携

保存した実践はメインアプリのLogsと今日の活動に反映されます。

Screens

画面ごとの役割

3分再起動。Start Console、Reminder、カテゴリ別の今日、Life Balance、Quick Log、時間配分。

Goals

長期目標をTask、Habit、Resourceへ分解する場所。

Knowledge

学びを溜める場所。ActionableならTodo化してTodayへ戻す。

Logs

活動ログ、日次レビュー、英語日記、カレンダー。

Learning Lab

Cloud QuestとSandboxで実践し、Learning Logへ保存する。

Projects

Project、Goal、Resourceの作戦部屋。

Operations

Notionとローカル保存

Notion整合性チェック

Settingsで不足DB IDと不足プロパティだけを表示します。Notion側の修正作業が分かりやすくなります。

ローカル保存

Focus Session、LifeScore、MoodLog、FinanceSnapshot、LearningTopicはまずlocalStorageに保存します。

同期失敗時

Notion保存に失敗してもローカルに残り、アプリの利用は止まりません。

flowchart TD
    A[Settings] --> B[Notion DB整合性チェック]
    B --> C{不足あり?}
    C -->|なし| D[OK]
    C -->|DB ID不足| E[Script Propertiesを修正]
    C -->|Property不足| F[Notion DBにProperty追加]
    E --> G[再チェック]
    F --> G
