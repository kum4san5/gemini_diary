Life Dashboard Guide

Life Dashboardの使い方

何を管理するかではなく、迷った時にどの画面で何を始めるかを確認するガイドです。

アプリに戻る AP Practice Learning Lab
ゴール 今やること 利用周期 画面 ケース データ 困った時 運用

Purpose

ゴールは、人生を管理し切ることではなく、次の小さな行動に戻れること

Life Dashboardは、Todo、学習、お金、健康、創作を一度に完璧に管理するアプリではありません。今日の状態を見て、今やることを1つ選び、必要なResourceを開き、5分だけ始めるためのホーム画面です。

  • 一目で分かる: 今日の状態と次の一手が3秒で見つかる。
  • すぐ始める: Resourceを探し直さず、5分/15分Timerへ進める。
  • 次につなげる: 実績をLearning Logに残し、Goalと弱点復習へ戻す。
このアプリを使えた日の成功条件

全項目を埋めることではありません。5分始めた、1問解いた、明日の一手を1つ決めた。そのどれかで十分です。

flowchart TD
    A[迷う・止まる・脱線する] --> B[Todayを開く]
    B --> C[次の一手を1つ選ぶ]
    C --> D[Resourceを開く]
    D --> E[5分だけ始める]
    E --> F[Learning Logに残す]
    F --> G[Goal・弱点・明日の一手へ]
    G --> B

Start Here

今アプリを開いたら、この順番だけでよい

機能を理解してから使う必要はありません。まずTodayで1回動き、必要になった機能だけ後から覚えます。

1

Todayを見る

「次の一手」に出ているTodoを確認します。全Todoは見なくて構いません。

2

5分を押す

気力があれば15分、迷っているなら5分だけを選びます。

3

Resourceを開く

教材、Notion、開発環境、AP Practiceなど必要な場所へ進みます。

4

一言残す

終わったら「何をやったか」だけLearning Logへ保存します。

「次の一手」が空の場合

Todayの「Todoを追加」で、今日始められる行動を1つだけ作ります。例: 「応用情報を5問」「READMEを1節直す」「20分散歩」。

First Setup

最初の10分で設定するもの

最初から全機能を設定すると続きません。次の5つが動けば、ひとまず完成です。

  • Goalを1つ: 「応用情報に合格」「アプリを公開」など、今一番進めたい方向。
  • Todoを1つ: 今日5〜30分で着手できる行動。
  • Resourceを1つ: 教材、URL、開発環境など、開始に必要な入口。
  • 5分Timerを1回: Start Consoleから開始と記録ができるか試す。
  • Quick Logを1件: 「15分、応用情報、ネットワーク復習」の程度で十分。

最初にやる

Goal 1件、Todo 1件、Resource 1件だけ作り、実際に5分動く。

最初はやらない

全Goalの登録、過去ログの移行、全時間の予定化、スコアの最適化。

Usage Rhythm

毎日すべての画面を使わない

画面ごとに利用周期を分けます。日常はTodayだけで完結し、整理や分析は決まった日に行います。

毎日: Today

次の一手、5分Timer、Resource、Quick Log。必要ならAP PracticeかLearning Labへ移動します。

週1回: Goals / Knowledge

Goalの進み具合、来週のTodo、学びから作るAction、曜日ごとの予定を整理します。

月1回: Life Balance / お金

幸福、健康、成長、お金、創作、休息の偏りと、資産の自由月数を確認します。

タイミング開く画面やること終わりの条件
朝・再開時Today次の一手を選び、5分開始Timerが動いた
作業後Quick Log / Logs時間と一言を記録実績が1件残った
日曜など週1回Goals / Knowledge / Day Planner来週のTodoと予定を置く次の一手候補がある
月末Life Balance / Finance偏りと自由度を見る来月変えることを1つ決めた
接続変更時SettingsNotion整合性を確認不足項目が分かった

Screens

画面ごとの「開く理由」と「終わりの条件」

機能名ではなく、いつ開くかで覚えます。毎日使う必要がない画面は、必要になるまで触らなくて構いません。

Today: 迷った時と、作業を始める時

開く時: 朝、帰宅後、SNSへ流れそうな時、中断から戻る時。

やること: 次の一手を見る → 5分/15分Timer → Resourceを開く → 記録。

補助機能: Reminderは戻るきっかけ、Day Plannerは仕事・遊び・移動を差し引いた時間設計、Life Balanceは状態確認です。

終わり: 何か1つ始めたらTodayの役目は完了です。

Goals: 長期目標を、今日できる行動へ分ける時

開く時: 目標が曖昧、TodoがGoalにつながっていない、週次レビューをする時。

やること: Goalを1つ選び、サブタスク、習慣、Resource、成功条件を確認します。

終わり: Todayへ戻せる5〜30分のTodoが1つできたら完了です。

Knowledge: 調べたことを、次の行動へ変える時

開く時: 学んだ内容、読書メモ、調査結果を後で使える形にしたい時。

やること: 要点を残し、実行が必要ならActionableにしてTodo化します。

終わり: 保存するだけの知識か、行動に変える知識か決まったら完了です。

Logs: 実績と振り返りを確認する時

開く時: 作業後、夜、週次レビュー、英語日記を書く時。

やること: 活動時間、分野、メモを残す。夜は良かったことと明日の一手だけでも十分です。

終わり: 今日やったことが1件見える状態になれば完了です。

Projects / Resources: 作業環境と関連情報を整理する時

開く時: 複数のGoalが同じ成果物につながる時、教材やURLを探す時間が長い時。

やること: ProjectにGoalとResourceをまとめ、Todoから開けるようにします。

終わり: Start Consoleから必要な場所を1クリックで開ければ完了です。

AP Practice: 応用情報を問題演習で進める時

開く時: 最新年度、年度別、分野別の問題を解く時。

やること: 1問解く → 即時採点 → 間違いを弱点復習へ → Learning Log保存。

注意: 「データ未追加」の年度は、公式IPA由来のJSON/CSVを追加すると演習できます。

終わり: 1問でも解けば完了です。

Learning Lab: CLIと疑似クラウドを手で試す時

開く時: ネットワーク、認証、IAM、DB、障害対応を操作で理解したい時。

Quest: 達成条件に沿って学ぶ。順番やロックはありません。

Sandbox: Quest外で自由にコマンドやCode Runnerを試す。

終わり: 分かったことか、分からなかったことをLearning Logへ残したら完了です。

Settings: Notion連携や保存状態を直す時

開く時: 同期できない、Notion DBを変更した、データを再読み込みしたい時。

やること: Notion整合性チェックで、DB ID不足とProperty不足を確認します。

終わり: 直すべき不足項目が特定できたら完了です。日常では開きません。

Use Cases

状況別に、どこから始めるか

応用情報を勉強したい

Todayで「応用情報を5問」を選ぶ → 5分開始 → AP Practiceで最新年度 → 間違いを復習へ → Log保存。

アプリ開発を進めたい

Todayで開発Todoを選ぶ → GitHub/ローカルResourceを開く → 15分作業 → 変更内容をLogへ。

何もやる気が出ない

Life Balanceで状態を一言確認 → 5分だけか、休息Todoを選ぶ → 「今日はここまで」でも記録する。

CLIを触って覚えたい

Learning Labの好きなQuestを選ぶ → Terminalでhelp → Cloud Consoleで状態確認 → 実践ログ保存。

一週間が散らかっている

Day Plannerで曜日を選ぶ → 仕事・遊び・移動を置く → 空いた時間にTodoを割り当てる。

調べて満足してしまった

Knowledgeへ要点を残す → ActionableをON → 5〜30分のTodoへ変換 → Todayへ戻る。

Data Model

記録は「集めるため」ではなく、次の一手を良くするため

Goal、Task、Resource、Learning Logは別々の台帳ではありません。Goalから今日のTaskを作り、実行に必要なResourceを開き、結果をLogとして戻す1本の流れです。

flowchart LR
    A[Goal
どこへ進むか] --> B[Task
今日何をするか]
    C[Knowledge
何を知ったか] --> B
    D[Resource
どこで始めるか] --> B
    B --> E[Focus Session
実際に始める]
    E --> F[Learning Log
何が進んだか]
    F --> G[Review
次に変えること]
    G --> B
    H[AP Practice / Learning Lab] --> F
データ答える質問更新頻度
Goalどこへ進みたいか月1回・必要時
Task今日、何を始めるか毎日・週次
Resourceどこを開けば始められるか追加時だけ
Learning Log何をどれくらいやったか作業後
Life Score / Mood今の自分に何が足りないか気になった日
Finance Snapshot選択肢と安心が増えているか月1回

Troubleshooting

迷った時と、うまく動かない時

何をしたらいいか分からない

Todayへ戻り、「次の一手」を1つだけ見ます。空ならTodoを1つ作り、5分Timerを押します。他の画面は閉じて構いません。

Todoが多すぎて選べない

「今日中」「Resourceがある」「見積30分以下」のどれかを満たすものを1つ選びます。残りの整理は週次レビューへ送ります。

記録が面倒で続かない

Quick Logで「分・領域・一言」だけ残します。理解度、タグ、関連Goalなどは毎回入力しなくて構いません。

Notionと同期できない

SettingsのNotion整合性チェックを開きます。DB ID不足とProperty不足が分けて表示されます。同期失敗中もローカルデータで利用できます。

AP Practiceに問題がない年度がある

「データ未追加」は故障ではありません。IPA公式問題を確認し、JSON/CSV化したデータをAP Practiceのインポートから追加します。

気分や体調が悪く、スコアを見たくない

スコアを改善する必要はありません。休息、散歩、睡眠準備も正当な次の一手です。「今日はここまで」を選ぶことも軌道修正です。

Operations

保存・同期・詳しい説明

日常利用では意識しなくて構いません。接続変更やデータ追加の時だけ確認します。

Notion整合性

Settingsで不足DB IDと不足Propertyを確認します。自動作成はせず、直すべき内容を表示します。

ローカル保存

Timer、AP進捗、Sandbox、同期失敗時データはlocalStorageに保存されます。共有PCでの利用には注意してください。
